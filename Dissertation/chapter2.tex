\section{Обзор различных подходов}

 \subsection{Полный перебор} 
 
При небольшом размере системы (короткие цепочки и малое число спинов) можно перебрать все возможные конфигурации и использовать весь набор для подсчета физических величин \cite{Schram_2011}.  Этот метод даёт точные результаты  для дискретных спинов. В случае непрерывных спиновых переменных, можно использовать полный перебор БСП фиксированной длины, генерируя большое количество спиновых конфигураций для каждого, что позволит также получить достаточно точные результаты для оценки средних значений наблюдаемых величин. 

Метод полного перебора крайне плохо масштабируется  из-за экспоненциального роста числа состояний и не может применяться для моделирования длинных полимерных цепочек. Современные алгоритмы перебора позволяют достичь длины $N\approx 30$–36 шагов на кубической решётке \cite{Schram_2011}. 

Мы используем метод полного перебора на коротких цепочках для верификации реализованного метода Монте-Карло по Марковской цепи \ref{MCMC}. 

 
 \subsection{Метод Монте-Карло} 
Метод Монте-Карло является универсальным методом для моделирования систем с большим  числом степеней свободы, в которых перебор невозможен \cite{Landau_Binder_2021, Barkema}.

Базовый метод Монте-Карло использует случайное выборочное усреднение: нужную величину представляют как математическое ожидание и оценивают средним по независимым случайным выборкам.  

При моделировании сложных систем, как правило, получение независимой выборки затруднено.
 Так, при моделировании БСП число конфигураций растет экспоненциально как $\mu^N$ \cite{Rensburg}, где  $\mu \approx  4.684039931(27) $ для случая $d=3$ \cite{clisby2007self},  а число возможных шагов для траектории случайного блуждания на кубической решетке  $(2d)^N = 6^N$. 
 Вероятность получить БСП при случайной генерации 
 экспоненциально мала для больших цепочек $N$  (так как убывает с $(\mu/6)^N$). 
 
 
 
 Для моделирования длинных полимерных цепей, как правило, применяются методы Марковского Монте-Карло с обновлениями состояния системы, сохраняющими число мономеров $N$, что соответствует моделированию канонического ансамбля. 
 В таких алгоритмах новое состояние генерируется посредством локальных перестроек цепи, удовлетворяющих условию отсутствия самопересечений, а принятие состояния происходит по  правилу Метрополиса.
  Примерами локальных и билокальных алгоритмов являются: (i) «змееподобный» ход, который мы применяем и подробнее обсуждаем в разделе \ref{subsection:snake}; 
 (ii) локальные повороты/изгибы цепи --- например, вращение части полимера вокруг случайно выбранного внутреннего звена или отражение короткого участка. 
  Для ускорения изучения пространства конформаций применяются нелокальные перестройки, такие как пивот-алгоритм \cite{madrasokal} . 
  В пивот-алгоритме случайно выбирается мономер в цепи в качестве опоры, и вся «хвостовая» часть цепи случайно поворачивается (например, на решётке выбирается случайная симметрия: вращение или отражение) вокруг этой точки. 
 
 
 Отдельный класс методов позволяет флуктуировать числу мономеров, т.е. включает обновления системы, не сохраняющие длину. 
 Такие алгоритмы работают, моделируя большой канонический ансамбль.
 Классическим примером является алгоритм Берретти–Сокала \cite{BerettiSokal}, в котором шаг моделирования состоит либо в добавлении нового звена в случайно выбранном месте цепи, либо в удалении существующего звена, с соответствующей поправкой весов, чтобы компенсировать различие чисел состояний для разных $N$. 
 Этот метод был адаптирован и реализован для моделирования динамической HP модели \cite{faizullina2021globule1}. Данный метод имеет недостатки: устойчиво работает лишь на сравнительно коротких цепочках и требует тонкой подстройки параметров (интенсивности добавления/удаления, весов), что затрудняет выбор универсальных настроек. Этот метод обсуждается в разделе \ref{MCMC_sokal}. 
 
 
 \subsection{ Метод Монте-Карло по Марковской цепи }
  \label{MCMC_description_general}
 
Для эффективного моделирования сложных систем одним из универсальных   методов является семейство методов Монте‑Карло по Марковским цепям (MCMC ).
Идея методов заключается в построении цепочки состояний, переходы в которой заданы так, чтобы её стационарное распределение совпадало с целевым. Такие методы позволяют эффективно изучать системы, где состояния распределены согласно распределению  Больцмана-Гиббса  \eqref{Zcanonical}.

Средние наблюдаемых, вычисленные по траектории Марковской цепи, сходятся к истинным ансамблевым средним \eqref{gibbs} при выполнении двух ключевых условий: эргодичности и детального баланса.


Эргодичность подразумевает, что любое состояние системы алгоритм может  достичь из любого другого за конечное число шагов с ненулевой вероятностью. Условие эргодичности гарантирует, что алгоритм  со временем исследует всё конфигурационное пространство.


Детальный баланс в физике означает, что в равновесии каждый переход (новое состояние) компенсируется обратным (поток переходов между любыми двумя состояниями уравновешен).
Условие детального баланса  обеспечивает сходимость к равновесному распределению.
Для пары состояний $u_0$ и $u_{new}$ это условие записывается в виде:

 \begin{equation}
	\label{detailedbalance}
	p_{u_0} P(u_0 \rightarrow u_{new} ) = p_{u_{new}} P( u_{new} \rightarrow u_0),
\end{equation}
где $P(u_0\rightarrow u_{new} )$ --- вероятность перехода из состояния $u_0$ в состояние  $u_{new}$. Здесь $p_{u_0},p_{u_{new}}$ --- стационарная вероятность нахождения в состоянии  $p_{u_0} = e ^{-H(u_0)}/Z $ из распределения Гиббса-Больцмана.   
 


Один из самых известных методов Монте-Карло по Марковской цепи --- метод Метрополиса  \cite{MetropolisOriginal}.
 Суть метода: генерируется новое состояние $u_{new}$, которое принимается с вероятностью  $P_{accept} = \min (1, e^{ - \Delta E})$, где $\Delta E$ ---  разность энергий между новым и текущим состоянием.

В качестве базового алгоритма был выбран алгоритм Берретти-Сокала \cite{BerettiSokal}, обобщённый на случай динамических внутренних состояний мономеров.

 При попытке роста цепи новое звено предлагалось в одном из соседних направлений от её конца. 
 Если предложенная конфигурация нарушала условие самонепересечения, переход отклонялся.
 Пример показан на рисунке \ref{fig:turtle}.

\section{Метод Монте-Карло по Марковской цепи для канонического ансамбля: 3  шага}
\label{MCMC}

В этом исследовании используется метод Монте-Карло на основе Марковских цепей для моделей, объединяющих спиновые переменные и динамическую геометрию.  Вдохновение из книги  \cite{Barkema} позволило адаптировать классические алгоритмы к поставленным задачам. 


\subsection{Метрополис (змееподобный алгоритм)}
\label{subsection:snake}

\begin{figure}
	\centering
	\includegraphics[width=0.45\textwidth]{images/snakeupdate.png}
	\caption{Пример "змееподобного алгоритма".}
	\label{fig:snakeupdate}
\end{figure}  

Для моделирования спиновых систем на динамической геометрии мы используем модифицированный "змееподобный алгоритм" (slithering snake algorithm/Reptation algorithm) \cite{Binder_Sokal_chapter}, основанный на методе Метрополиса  \cite{MetropolisOriginal}.  Это классический метод, применяемый для моделирования БСП в каноническом ансамбле. Генерация нового состояния - это последовательность следующих шагов: 1) Выбирается один из концов цепочки; 2)  Удаляется выбранный конец в шаге 1; 3) добавляет новый узел блуждания в случайном направлении на другом конце \ref{fig:snakeupdate}.   

В диссертационной работе рассматриваются системы, где спиновые состояния динамичные, поэтому при генерации нового состояния алгоритмом мы также  генерируем случайное спиновое значение для нового мономера. Общая схема этого алгоритма в наших реализациях выглядит так:

 \begin{enumerate}
\item Фиксируется  текущее состояние системы  $u_0$. 

\item  Выбирается один из концов цепочки, который предполагается для удаления. 

\item  Выбирается случайным образом из равномерного   распределения одно из  $2 \times d$ направлений ($d $ - размерность пространства). В это направление должен добавиться новый мономер на другом конце цепочки. 

\item Проверяется условие на самопересечение: в цепочке не должно быть узла в новой координате. Если условие на отсутствие самопересечений не выполняется, то новое состояние отклоняется и генерация начинается с шага 1.

 \item Удаляется выбранный конец цепочки в шаге 2. Добавляется новый мономер в координату, определенную на шаге 3. 

 \item Для нового мономера БСП генерируется  переменная из спинового пространства. Генерация нового состояния $u_{new}$  завершается. 
 
 
 \item  Новое сгенерированное состояние  $u_{new}$ принимается по правилу Метрополиса:
 \begin{equation}
 	\label{accratios}
 	A(u_0  \rightarrow u_{new} ) =  
 	\begin{cases}
 		e^{-J(E_{u_{new}}-E_{u_0})}, & \text{if $E_{u_{new}}-E_{u_0}>0$;}\\
 		1, & \text{иначе}.
 	\end{cases} 
  \end{equation}


\end{enumerate}

  \textbf{Детальный баланс}. 

Для генерации состояний системы согласно распределению Больцмана-Гиббса, вводится коэффициент принятия перехода $A(u_0  \rightarrow u_{new} )$: 
\begin{equation*}
	P(u_0  \rightarrow u_{new} ) = g(u_0  \rightarrow u_{new} ) A(u_0  \rightarrow u_{new} ),
\end{equation*}

где $g(u_0  \rightarrow u_{new} )$ вероятность  сгенерировать алгоритмом  состояние $u_{new} $ из состояния  $u_0$. 
 Здесь $ A(u_0  \rightarrow u_{new} )$ --- вероятность алгоритмом принять новое состояние $u_{new} $ и изменить состояние системы в   конфигурацию $u_{new} $. 
 
  Условие детального баланса \eqref{detailedbalance} может быть записано в следующем виде: 
 
  
 \begin{equation}
 	\label{detailedbalance_ratio} 
 	\frac{P(u _0 \rightarrow u_{new} )}{P( u_{new} \rightarrow u_0 ) } = 
 	\frac{g(u_0  \rightarrow  u_{new}) A(u_0  \rightarrow  u_{new} )}{g(  u_{new}  \rightarrow u_0 ) A(  u_{new}  \rightarrow u_0 )}
 	= \frac{p_{u_{new}}}{p_{u_0 }} = e^{- J(E_{u_{new}}-E_{u_0})} . 
 \end{equation} 
 
   Принятие нового состояния по правилу Метрополиса  \eqref{accratios}  гарантирует выполнение условия детального баланса \eqref{detailedbalance_ratio} \cite{MetropolisOriginal}. 
 
 Для модели Изинга вероятности сгенерировать новое состояние $\ g( u_0  \rightarrow  u_{new} )  = g(  u_{new}  \rightarrow u_0 )  = \frac{1}{2 \times 2 \times d }$, так как есть $ 2 \times d $ вариантов направлений  для нового мономера и 2 возможных состояния спина.  
 Новые состояния выбираются равновероятно.
 Аналогично, для модели XY с непрерывными спинами выполняется условие $\ g( u_0  \rightarrow  u_{new} )  = g(  u_{new}  \rightarrow u_0 )  $  : на решетке  есть  $ 2 \times d $ направлений для новой геометрической конфигурации и угол  $\theta_{new}$  генерируется согласно равномерному непрерывному распределению $\theta_{new} \sim U(-\pi, \pi)$. 


 \textbf{Оценка алгоритма}. 
 
 Змееподобный алгоритм относится к билокальным методам \cite{Binder_Sokal_chapter}: за один успешный шаг обновляется только один мономер.  
 Следовательно, изменения по цепи распространяются медленно. Это даёт высокую автокорреляцию, особенно для глобальных свойств (например, радиусов и намагниченности), что увеличивает время сбора статистики. 
 
 По нижней оценке, соответствующей развернутому состоянию в сильных растворителях (область низких значений для параметра $J$), для достижения независимых конфигураций требуется $~ O (N^2)$ шагов Монте-Карло \cite{Binder_Sokal_chapter, BerettiSokal}. % в моделях с близким взаимодействием. 

\subsection{Смена соединений} 
\label{subsection:reconnect} 


\begin{figure}

	\caption{Пример смены соединений в конфигурации. Координаты спинов и их значения не меняются в данном виде генерации состояния.}
	\label{fig:reconnect}

Для  повышения эффективности исследования геометрического состояния алгоритмом, мы также используем метод смены соединений в конфигурации \cite{PhysRevLett.87.160601}. Пример такого шага алгоритма показан на рисунке \ref{fig:reconnect}. 

Смена соединений -  это глобальный ход, при котором один участок цепи временно разрывается и пересоединяется в другом месте, сохраняя связность и избегая самопересечений. 

Данная часть алгоритма меняет только соединения в геометрической конфигурации, но не  передвигает узлы и не генерирует новые спиновые состояния. 
В изучаемых данной работе моделях гамильтонианы систем  \eqref{hamiltonian_ising} и  \eqref{hamiltonian_xy}  не зависят от связности цепи, а множество взаимодействующих неповторяющихся пар спинов $\mathcal E$  зависит лишь от положений спинов на решетке. 
 Следовательно, если новое состояние удалось сгенерировать - условия на отсутствие самопересечений не нарушено - оно всегда принимается согласно правилу Метрополиса, так как   $\Delta E = 0 $. 


\begin{figure}
	\centering
	\includegraphics[width=0.35\textwidth]{images/snakeproblem.png}
	\caption{Пример замороженного состояния.}
	\label{fig:reconnect_fix}
\end{figure}   


Такой алгоритм позволяет системе выйти из замороженных состояний  \ref{fig:reconnect_fix}, что на рассматриваемых размерах  улучшает эффективную эргодичность моделирования (что полезно, даже если вероятность таких состояний мала). 

 \textbf{Оценка алгоритма}.  
 
  При успешной генерации нового геометрического состояния в среднем меняются соединения y  $N/2$ узлов в БСП. 
Добавление смены соединений  позволяет  снизить  автокорреляцию  глобальных наблюдаемых примерно на порядок по сравнению с чистым змееподобным‑алгоритмом при сопоставимых суммарных вычислительных затратах.  


\subsection{Кластерная генерация спиновой конфигурации}
 

Мы применяем классический алгоритм Вольфа \cite{PhysRevLett.62.361}. Данный алгоритм повышает эффективность изучения спиновых конфигураций. 

Основная идея алгоритма заключается в формировании кластера $C$ и перевороте его спинов. 
Правила принятия нового состояния должны подчиняться условию детального баланса. 
Мы следуем классическому способу реализации кластерного обновления для модели XY, обсуждаемому в работе \cite{Barkema}.

	\caption{ Кластерная генерация для XY модели на БСП.  }
	\label{fig:ClusterUpdate}
\end{figure}

Генерация нового состояния с помощью кластерного алгоритма состоит из следующих шагов. 

\begin{enumerate}
	
	\item Случайно выбирается один спин  $\overrightarrow{S_{start}}$, используя  дискретное равномерное распределение (всего $N$ значений, где $N$ --- длина цепочки).
Алгоритм добавляет этот  спин к кластеру $C$ и отмечаем его как  проверенный.
	Также этот спин добавляется во временный массив $C_{temp}$ для обхода его соседей.  
	
	\item Случайно выбирается направление на единичной окружности $\overrightarrow{n}$ с использованием равномерного непрерывного распределения $ \theta_{new} = U(-\pi, \pi)$: $\overrightarrow{n} = [\cos(\theta_{new}), \sin(\theta_{new})]$.

	\item Берется следующий спин $ \overrightarrow{S_{i}}$  из временного массива $C_{temp}$ , чтобы посетить всех его соседей $S_j$ (  пример обхода соседних узлов показан на графике \ref{fig:clustergrowth} ). 
	Новый спин добавляется в кластер только если проекции спинов на направление $\hat{\mathbf n}$ имеют одинаковый знак, то есть $( \overrightarrow{S_{i}}\overrightarrow{n} )( \overrightarrow{S_j}\overrightarrow{n} )>0$. 
	
 Новый спин добавляется в кластер $C$ с вероятностями $P_{add}(\overrightarrow{S_{i}}, \overrightarrow{S_j} ) = 1 - \exp \left(-2J (\overrightarrow{S_{i}}\overrightarrow{n})( \overrightarrow{S_j} \overrightarrow{n} ) \right)$, где  $\overrightarrow{S_{i}}\overrightarrow{n}$ --- скалярное произведение. 

	
	После посещения всех соседей спина $ \overrightarrow{S_{i}}$,  узел   $ \overrightarrow{S_{i}}$ отмечается как проверенный и  удаляется из временного массива $C_{temp}$.
	
	\item Обход соседей выполняется, пока временный массив $C_{temp}$ не останется пустым. 
	 
	 \item Осуществляется переворот собранного кластера $C$. Спин $\overrightarrow{S_j} $ из кластера обновляется через вычитание отраженного вектора: $\overrightarrow{S_j} : = \overrightarrow{S_j} - 2 \times ( \overrightarrow{S_j} \vec{n}) \vec{n}$. 

\end{enumerate}

\textbf{Кластерная генерация для  модели Изинга}. 
 

Для модели Изинга со спинами $s_i \pm1 $ выбор  нового значения спина не требуется.
Кластер растёт из случайно выбранного узла $i_{start}$ так же, как в случае модели XY на БСП. Соседний мономер $j$ добавляется в кластер 
только если значения спинов  совпадают, $s_i=s_j$ с вероятностью $P_{\text{add}}(i,j)=1-\exp\!\bigl[-2  J \bigr]$. 
После завершения роста кластера все спины в нём одновременно переворачиваются:
 $ s_i \leftarrow -\,s_i\,,\qquad i\in C$.


 \textbf{Оценка алгоритма}.   
 
 
 Кластерный апдейт строится так, что финальный групповой переворот кластера принимается с вероятностью $1$ (шага Метрополиса  в финале нет). 
 Типичный размер кластера $\langle\lvert C\rvert\rangle$ возрастает при приближении к критической области и может быть порядка $N$ в окрестности критической точки (обсуждения алгоритма в  \cite{Barkema}).
 Благодаря этому интегральные автокорреляционные времена, например, для намагниченности и  для энергии, растут существенно медленнее, чем при локальных алгоритмах. 
 


\subsection{Реализация численного метода}
\label{implementation}

Метод реализован на языке C++. 

Для оптимизации программы был использован технический приём: решётка представляется как тор (периодическая индексация по модулю $N$ --- длины цепочки), что позволяет заранее сгенерировать конечный массив узлов и таблицу соседей размера $N^2 \times 2d$, где $d$ --- размерность пространства, а $2 \times d$ --- число направлений.
 Сам полимер при этом живёт «как на обычной решётке», с открытыми границами: периодичность служит только для подготовки предвычислений  и использования  кэш-локальности, физические граничные условия на модель не накладываются. 
Хранение координат и спинов в компактных непрерывных массивах (кольцевой буфер для цепи с головным/хвостовым указателями) и массив занятости решетки дают  $O(1)$ по времени и дополнительной памяти на один шаг змееподобного алгоритма: удаление хвоста, выбор нового спина, проверка пересечений по массиву и добавление нового узла  выполняются через несколько предвычисленных обращений к массиву, содержащему таблицу соседей. 
Такая схема минимизирует случайные обращения к памяти и эффективно использует кэш процессора.

Использование предвычисленных массивов решеток требует большого объема оперативной памяти. Вычисления проводились на кластере НИУ ВШЭ \cite{cHARISMa2021}.

Для покрытия широкого диапазона состояний  можно использовать классический прием \cite{Bachmann2011MonteCS, doi:10.1142/9789814417891_0003} ---  в ходе компьютерного моделирования реализовать обмен репликами  (состояний) \cite{PhysRevLett.57.2607}, а при анализе данных объединить результаты нескольких моделирований  при разных значениях параметра $J$ с  использованием метода мультигистограммного перевзвешивания \cite{PhysRevLett.63.1195}.  
В тексте данной диссертации  для дополнительной проверки опубликованных качественных выводов  \cite{faizullina2021critical1, rp7y-13mp}  приведены результаты, полученные в результате  численного эксперимента, в котором использовались обмен репликами и мультигистограммное перевзвешивание.  


\subsection{Параллельное темперирование (Обмен репликами)}

Метод параллельного темперинга (обмен репликами) позволяет повысить эффективность изучения пространства состояний  при компьютерном моделировании  \cite{PhysRevLett.57.2607}. 
Добавление такого шага в реализацию численного моделирования  сокращает длительное время автокорреляций, характерных для стандартных прямых методов (использование одного зафиксированного в ходе моделирования параметра $J$ ), позволяя исследовать более низкие температуры с меньшими затратами вычислительного времени, что особенно эффективно при наличии фазовых переходов первого рода. 

В методе одновременно моделируются $M$ реплик одной и той же системы при различных зафиксированных значениях параметра взаимодействия:
\[
J_1 < J_2 < \dots < J_M .
\]
Совместное стационарное распределение всех реплик ${u_m}$ имеет следующий вид:
\begin{equation}
	\Pi(\{u_m\})=
	\prod_{m=1}^{M}\frac{1}{Z(J_m)}\exp\!\left[-J_m E(u_m)\right].
\end{equation} 

Для каждой  цепочки между попытками обмена выполняются стандартные шаги    Метрополиса и Смены соединений (описаны в разделе \ref{MCMC}), сохраняющие каноническое распределение при фиксированном $J_m$. Кластерный шаг в данной реализации пропущен, так как стратегия использования обмена репликами состоит в использовании быстрых и легко реализуемых змееподобных шагов Метрополиса и смены соединений, которые не требуют в рамках спиновых моделей на БСП полного пересчета энергии для последующего обобщения метода на модели с учетом дальнодействия. 

Если до обмена реплики содержат состояния $u_m$ и $u_{m+1}$, то вероятность принятия обмена репликами по правилу Метрополиса \eqref{accratios} получается из условия детального баланса \eqref{detailedbalance} для совместного распределения следующая: 


Если до обмена реплики содержат состояния $u_m$ и $u_{m+1}$,  то правило Метрополиса  \eqref{accratios}  для обмена репликами получается из отношения совместных вероятностей состояний  \eqref{gibbs}  до и после перестановки значений параметров $J_m$ и $J_{m+1}$:
\begin{equation}
	A_{\mathrm{PT}}=
	\min\!\left\{
	1,\,
	\exp\!\Bigl[(J_m-J_{m+1})
	\bigl(E(u_m)-E(u_{m+1})\bigr)\Bigr]
	\right\}.
	\label{eq:pt_swap}
\end{equation}
 
Добавление такого шага не изменяет равновесное распределение каждой реплики, но позволяет алгоритму эффективнее совершать случайное блуждание по параметру $J$: при меньших $J$ система легче преодолевает энергетические барьеры, после чего конфигурация может вернуться в область больших $J$ уже в другой части  пространства состояний. 

 Эффективность метода зависит от выбора набора значений $J_m$ при численном эксперименте. Соседние реплики выбираются так, чтобы распределения энергии при $J_m$ и $J_{m+1}$  значительно перекрывались   \cite{Katzgraber_2006, PhysRevLett.101.130603, 10.1063/1.1917749}, в противном случае обмены происходят слишком редко и выигрыш от параллельного темперирования уменьшается. 
 В данной работе при моделировании с использованием параллельного темперинга  обмены репликами выполнялись только между соседними значениями параметра $J$. По сырым данным прямого численного моделирования, интервал значений $J$ был заранее определен. 

Если такой шаг реализован с применением моделирования на GPU, то один запуск компьютерного моделирования покрывает несколько значений параметра взаимодействия $J$, которые потом можно эффективно постобработать. 
В текущей реализации, описанной выше в разделе \ref{implementation}, число цепочек, которые одновременно моделируются, ограничено оперативной памятью. 

\subsection{Мультигистограммное перевзвешивание} 

Метод мультигистограммного перевзвешивания позволяет объединить результаты нескольких независимых моделирований, выполненных при различных значениях параметра $J$, в единую оценку термодинамических зависимостей \cite{PhysRevLett.61.2635, PhysRevLett.63.1195}. 
В отличие от прямого анализа каждой выборки по отдельности, данный подход использует информацию из всех построенных гистограмм одновременно.
 Это позволяет уменьшить статистические ошибки и восстанавливать средние значения наблюдаемых величин в непрерывном интервале значений $J$ без запуска отдельного моделирования для каждой точки.

Практически метод основан на том, что гистограммы энергии, полученные при близких значениях параметра $J$, имеют область перекрытия. 
Именно эта область делает возможным самосогласованное объединение данных из разных реплик и последующее перевзвешивание выборки на промежуточные значения параметра. 
В данной работе мультигистограммное перевзвешивание используется как инструмент постобработки результатов параллельного темперирования для более точного восстановления температурных зависимостей энергии, теплоёмкости и других наблюдаемых.
 
Пусть при фиксированном значении параметра $J_m$ выполнено численное  моделирование, в котором получено $N_m$ измерений энергии. 
Пусть $H_m(E)$ --- эмпирическая  гистограмма энергии, полученная численным моделированием; а  $\Omega(E)$ --- плотность состояний системы. 
Тогда каноническое распределение энергии имеет вид:
\begin{equation}
	P_m(E)=\frac{\Omega(E)e^{-J_m E}}{Z(J_m)},
	\label{eq:canon_energy_dist}
\end{equation}
где статистическая сумма принимает следующий вид: 
\begin{equation}
	Z(J_m)=\sum_E \Omega(E)e^{-J_m E}  . 
	\label{eq:partition_from_dos}
\end{equation}
 
Численная гистограмма $H_m(E)$ оценивает распределение $P_m(E)$ по выборке длины $N_m$:
 \begin{equation}
 	\frac{H_m(E)}{N_m}\approx P_m(E). 
 \end{equation}

Каждое отдельное численное  моделирование даёт оценку плотности состояний:
\begin{equation}
	\Omega(E)\approx \frac{H_m(E)}{N_m}\, Z(J_m)e^{J_m E}.
	\label{eq:single_hist_dos}
\end{equation}

Если гистограммы, полученные при разных $J_m$, перекрываются по энергии, их можно объединить в единую оптимальную оценку плотности состояний \cite{PhysRevLett.63.1195}:
\begin{equation}
	\hat \Omega(E)=
	\frac{\sum\limits_{m=1}^{M} H_m(E)}
	{\sum\limits_{m=1}^{M} N_m \exp\!\left[-J_m E+f_m\right]},
	\label{eq:fs_dos}
\end{equation}
где $
	f_m=-\ln Z(J_m)$ .
 
% Формула \eqref{eq:fs_dos} получается из \eqref{eq:single_hist_dos} при статистически оптимальном объединении всех доступных оценок $n(E)$.

Неизвестные величины $f_m$, зависящие от статистической суммы, находятся численно из условия нормировки:
\begin{equation}
	e^{-f_m}=Z(J_m)=\sum_E \hat  \Omega(E)e^{-J_m E}.
	\qquad m=1,\dots,M.
	\label{eq:fs_selfconsistent}
\end{equation}
%Уравнения \eqref{eq:fs_dos}--\eqref{eq:fs_selfconsistent} решаются итерационно до сходимости. 

После этого для любого промежуточного значения параметра $J \in [  J_1 ; J_M ]$ можно восстановить каноническое распределение и вычислить средние наблюдаемых. Если наблюдаемая величина зависит только от энергии, $O=O(E)$, то её среднее при произвольном $J \in [  J_1 ; J_M ] $  находится следующим образом: 
\begin{equation}
	\langle O \rangle_J =
	\frac{\sum_E O(E)\hat  \Omega(E)e^{-J E}}
	{\sum_E \hat  \Omega(E)e^{-J E}}.
	\label{eq:obs_from_dos}
\end{equation}



Эффективность метода зависит от достаточности перекрытия соседних   гистограмм энергии: при значительном перекрытии объединённая оценка $\hat n(E)$ оказывается существенно точнее, чем оценка, построенная по одной реплике. В данной работе перевзвешивание применяется на данных, полученные с использованием алгоритма обмена репликами, который в свою очередь также зависит от энергетических перекрытий.

 \subsection{Биннинговый анализ коррелированных данных}
 
 Данные наблюдаемой физической величины $x$ (временной ряд), получаемые реализованным методом Монте-Карло \ref{MCMC} коррелированы, поэтому стандартная ошибка среднего \(\mathrm{SE}(\bar x)=\sqrt{\mathrm{Var}(x)/N}\) занижает истинную неопределённость.
 Мы используем биннинговый (blocking) анализ, при котором данные усредняются по блокам растущего размера, а дисперсия оценивается на основе средних блоков;  корректность обеспечивается при выходе дисперсии на плато по размеру блока \cite{10.1063/1.457480}.
 
 При применении биннингового анализа, фиксируется размер блока \(b\).  Последовательность (временной ряд) разбивается на \(M=\lfloor N/b\rfloor\) неперекрывающихся блоков. Для каждого блока вычисляется среднее значение:
 \[
 y_k=\frac{1}{b}\sum_{t=(k-1)b+1}^{kb} x_t,\qquad k=1,\dots,M.
 \]
 Оценка среднего на текущем уровне разбиения при заданном $b$:
 \[
 \bar y=\frac{1}{M}\sum_{k=1}^M y_k.
 \]
 Оценка стандартной ошибки по блокам:
 \[
 \mathrm{SE}_b=\frac{\sqrt{\max\!\bigl(0,\ \overline{y^2}-\bar y^{\,2}\bigr)}}{\sqrt{M}},
 \quad
 \overline{y^2}=\frac{1}{M}\sum_{k=1}^M y_k^2.
 \]
 
 Начиная с \(b=1\), формируется последовательность уровней биннинга \(l=0,1,2,\dots\).
 Переход на следующий уровень выполняется попарным слиянием соседних блоков:
 \[
 y^{(l+1)}_k=\frac{1}{2}\Bigl(y^{(l)}_{2k-1}+y^{(l)}_{2k}\Bigr),\qquad
 M_{l+1}=\Bigl\lfloor \frac{M_l}{2}\Bigr\rfloor,\qquad
 b_{l+1}=2\,b_l.
 \]
 На каждом уровне пересчитываются \(\bar y^{(l)}\) и \(\mathrm{SE}^{(l)}\).  
 
 Для биннингового(блочного) анализа использовалась реализация \cite{mc_lib_v041}.
 

\subsection{Парная регрессия для оценки точек фазовых переходов}


\label{subsection:paired_regression} 
 Точки фазовых переходов оцениваются с помощью метода парных регрессий для  масштабированных кривых радиусов $ \frac{\langle R_N^2\rangle}{N^{2\nu_\Theta}} $ (при изучении структурного перехода)  и кумулянтов Биндера  \eqref{binder_cumulant} (при изучении магнитного перехода). 

Основная идея метода --- применение линейной аппроксимации данных, полученных компьютерным  моделированием. 
Метод применяется на наборе данных, срезанных по узкому интервалу  значений параметра взаимодействия $J \in [J_{min}, J_{max}]$, который покрывает точку фазового перехода. 

Рассмотрим метод парных регрессий для оценки точки магнитного перехода на данных кумулянта Биндера $U_4$. Выберем длину цепочки $N_{fixed}$ для анализа эффекта конечной длины. 

 \begin{enumerate} 
 	
 	\item  Выбираются  данные для двух цепочек разной длины $N_{fixed}, N_i$  из узкого диапазона $J \in [J_{min}, J_{max}]$. 
 	\item Для каждой пары значений $(N,J)$ вычисляется оценка кумулянта Биндера и его ошибка. 
 	Для этого используется генерация выборки для моментов намагниченности из распределений Гаусса, параметры которых - это среднее моментов и их ошибки. 
 	
 	\item  Так получаются две кривые кумулянтов биндера $U_4$ с погрешностями для двух значений длины цепочки $N_{fixed}, N_i$.  Применяется  взвешенную регрессия, учитывающая статистическую погрешность, для  приближения двух кривых прямыми линиями.
 	
	\item   Используя линейную аппроксимацию, найдем точку пересечения двух линий. Это и есть полученная оценка для $\hat{J_i}^{fixed} $.
 	
  \end{enumerate}

При анализе всех доступных в вычислительных данных пары $N_{fixed}, N_i$,   получается функциональная зависимость оценки критической точки $\hat{J}_{cr}^{fixed}$ от размера парной цепи $N_i$. 
Рассматривая функцию $\hat{J}^{fixed} = \hat{J}_{cr}^{fixed} (1/N_i)$, можно найти её нулевое значение: $\hat{J}_{cr}^{fixed} (0)$.  
Это значение соответствует термодинамическому пределу  $N_i \rightarrow \infty$.


Повторение парных регрессий и аппроксимация точек пересечения относительно $(1/N_i)$ позволяет нам экстраполировать данные до термодинамического предела.
 Метод позволяет проанализировать, как эти точки пересечения изменяются в зависимости от размера системы и обеспечивает систематический способ анализа эффектов конечного размера.
