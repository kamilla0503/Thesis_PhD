Численное исследование спиновых моделей на динамических структурах. 


% Trapped Rydberg ions  



\paragraph*{Актуальность темы.}

Магнитные системы являются упрощенными моделями реальных физических систем. 


Модели с дальнодействием представляют собой систему, в которой каждый спин взаимодействует со всеми остальными спинами обратно пропорционально расстоянию между ними. Такая модель отражает поведение диполь-диполь взаимодействия между мономерами в молекуле. 

%Изучение спиновых систем с замороженным беспорядком позволяет ответить на вопрос, как топология и геометрия влияют на магнитные степени свободы.

%Тема международно академически признанная, Таулесс,  Халдейн и Костерлитц получили премию в 2016 году за изучение фазовых переходов. 

\paragraph*{Цель работы.}

Провести численное моделирование  спиновых систем на регулярной решетке с динамической геометрией. 

\paragraph*{Задачи работы.}

\begin{enumerate}
	\item Разработать метод вычислительного моделирования спиновых систем на регулярной решетке с замороженным беспорядком, порождаемым случайными блужданиями без самопересечений (СБС). 
	
	\item Провести моделирование спиновых систем с динамической геометрией с помощью реализованного метода. Применить метод для моделей Изинга и ХУ на СБС. 
	
	
	\item Проанализировать полученные численные данные. При наличии фазового перехода в системе дать его характеристику. 
	
\end{enumerate}

\paragraph*{Научная новизна работы.}

\begin{enumerate}
	\item Разработан метод моделирования спиновых систем на регулярной решетке с замороженным беспорядком, порождаемым случайными блужданиями без самопересечений (СБС). 
 Реализованный подход расширяет возможности изучения  спиновых моделей с динамическим беспорядком. 
С помощью    разработанного метода проведено моделирование систем с дискретными спинами (модель Изинга) и непрерывными спинами (модель XY).

\item Разработан подход для анализа численных данных спиновых систем с динамически изменяющейся геометрией. 
Проведена характеристика поведения таких систем на СБС вблизи точек фазового перехода для модели Изинга и, впервые, для XY-модели.
	
\end{enumerate}

\paragraph*{Теоретическая и практическая значимость работы.}

Развитии теоретического понимания поведения спиновых систем на динамически изменяющихся решётках, генерируемых случайными блужданиями без самопересечений. Полученные результаты расширяют представления о взаимосвязи между магнитными и структурными фазовыми переходами в полимерных системах. 

Предложенная и реализованная методика численного моделирования  для изучения полимерных и магнитных систем --- практическая значимость данной работы.

\paragraph*{Положения выносимые на защиту.}


\begin{enumerate}
	\item  Адаптация метода Монте-Карло к моделированию спиновых систем с динамически изменяющейся геометрией. 
Разработанный метод позволяет исследовать спиновую модель на случайной траектории, создавая новые конфигурации за счет случайного блуждания без самопересечения (СБС). 

\item Численно исследована модель Изинга на динамических структурах, генерируемых случайными блужданиями без самопересечений на регулярной решетке. Численные данные показывают, что структурный переход между глобулярным и развернутым состояниями полимерной цепочки происходит одновременно с магнитным переходом из ферромагнитного (упорядоченного) в парамагнитное (неупорядоченное) состояние. 
На квадратной решетке  наблюдается магнитный переход второго рода. 
%На кубической решетке, наблюдается фазовый переход первого рода. 
Произведены оценки критического показателя корреляционной длины в критической области перехода клубок-глобула. Оказывается, что критический показатель унаследован от ``родительской'' модели --- классического гомополимера. 

\item Впервые численно исследована модель XY на случайных блужданиях без самопересечений на квадратной и кубической решетках. 
 Показано наличие фазового перехода между глобулярным и развернутым состояниями полимерной цепочки; при этом критический показатель корреляционной длины соответствует показателю родительской модели - гомополимера. 
В трехмерном случае данные моделирования сигнализируют о магнитном переходе первого рода. Установлено, что магнитный фазовый переход является непрерывным в двумерном случае и переходом первого рода — в трёхмерном, что качественно аналогично поведению родственных моделей с изинговскими спинами.

% \item Метод  Монте-Карло на Марковской цепи  расширен для изучения модели XY на блужданиях без самоперсечений с дальнодействием. 
\end{enumerate}
