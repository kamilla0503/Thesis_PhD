% Trapped Rydberg ions  


Магнитные системы являются упрощенными моделями реальных физических систем. 



Модели с дальнодействием представляют собой систему, в которой каждый спин взаимодействует со всеми остальными спинами обратно пропорционально расстоянию между ними. Такая модель отражает поведение диполь-диполь взаимодействия между мономерами в молекуле. 

Изучение спиновых систем с замороженным беспорядком позволяет ответить на вопрос, как топология и геометрия влияют на магнитные степени свободы.


Тема международно академически признанная, Таулесс,  Халдейн и Костерлитц получили премию в 2016 году за изучение фазовых переходов.

\paragraph*{Научная новизна работы.}

\begin{enumerate}
	\item Разработан метод моделирования спиновых систем {\color{blue} на решетке} с замороженным беспорядком, порождаемым случайными блужданиями без самопересечений (СБС). 
С помощью  {\color{blue} разработанного} метода проведено моделирование систем с дискретными спинами (модель Изинга) и непрерывными спинами (модель XY).

\item Разработан подход для анализа численных данных спиновых систем с динамически изменяющейся геометрией. 
Проведена характеристика поведения таких систем на СБС вблизи точек фазового перехода для модели Изинга и, впервые, для  {\color{blue}XY-модели}.
	
\end{enumerate}

\paragraph*{Теоретическая и практическая значимость работы.}

\paragraph*{Положения выносимые на защиту.}


\begin{enumerate}
	\item  Адаптаптация метода Монте-Карло к моделированию спиновых систем с динамически изменяющейся геометрией. 
Разработанный метод позволяет исследовать спиновую модель на случайной траектории, создавая новые конфигурации за счет случайного блуждания без самопересечения.

\item Численно исследована модель Изинга при случайном блуждании по квадратной и кубической решетка: в двухмерном случае наблюдается магнитный переход второго рода, а в трехмерном — первого рода.
Критический показатель корреляционной длины в критической области перехода клубок-глобула унаследован от ``родительской'' модели --- классического гомополимера. 

\item Впервые численно исследована модель XY при случайном блуждании на квадратной и кубической решетках. 
Результаты показывают наличие структурного перехода между глобулярным и развернутым состояниями, при этом критический показатель  корреляционной длины наследуется от родительской модели.
В трехмерном случае данные моделирования сигнализируют о магнитном переходе первого рода. 

\item Метод  Монте-Карло на Марковской цепи  расширен для изучения модели XY на блужданиях без самоперсечений с дальнодействием. 
\end{enumerate}
